# Decision records

One short file per decision a future agent might otherwise re-litigate:
`NNNN-kebab-title.md`, numbered in order. Template:

```markdown
# NNNN — Title
**Date:** YYYY-MM-DD · **Status:** accepted | superseded by NNNN

## Context
What forced a choice.
## Decision
What we chose.
## Rejected
Alternatives and why not.
## Consequences
What this makes easy/hard; rules others must follow.
```
